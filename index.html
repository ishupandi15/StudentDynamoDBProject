Project Overview

This cloud-native Student Records CRUD system demonstrates data ingestion, processing, and analytics in AWS. Includes DynamoDB table creation, JSON ingestion, CRUD operations, Grade ‘A’ querying, gender analysis, and exporting data to S3.
