Project Overview

This project implements a Student Records CRUD system — a hands-on exercise in designing cloud workflows with DynamoDB and S3. It demonstrates data ingestion from a JSON file, Create/Read/Update/Delete operations, targeted queries (students with grade 'A'), gender counts, and a final JSON export for backup or downstream analytics.

No preview available? Download students.json to try locally or import into the demo.

Technologies & Tools Used

AWS Cloud9 AWS DynamoDB AWS S3 Python 3 (boto3) JSON / JSQL Git & GitHub
  • Create DynamoDB table (StudentRecords) with partition key student_id
  • Insert data from students.json into the table
  • Implement viewAll, updateStudent, deleteStudent scripts
  • Query students with grade 'A' and count gender distribution
  • Export all records to S3 as JSON

Implementation Workflow

Part A — Table Setup createTable.py — defines StudentRecords (student_id partition key)
Part B — Data Ingestion insertFromFile.py — loads students.json into DynamoDB
Part C — CRUD Operations viewAllStudents.py, updateStudent.py, deleteStudent.py
Part D — Queries & Export queryStudents.py + uploadToS3.py (Grade A + gender count + S3 export)
